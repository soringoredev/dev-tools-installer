Quick bash script to set up essential tools for developers on a fresh Ubuntu system.


Quick bash script to set up essential tools for developers on a fresh Ubuntu system.

## What it installs
- Git
- Java (OpenJDK 17)
- Python 3 + pip
- curl & wget
- (optional) VS Code
- (optional) Node.js + npm

## How to use

```bash
chmod +x install-dev-tools.sh
./install-dev-tools.sh
